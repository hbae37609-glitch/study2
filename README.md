# ⚡ 스카배틀 (SkaBattle)
> **스터디카페 위치 기반 친구 탐색 및 1:1 순공 대결 플랫폼**

학생들이 친구들의 실시간 스터디카페 위치를 확인하여 함께 공부하러 가고, 순수 공부 시간(순공) 측정과 친구 간 1:1 대결 및 누적 상대전적(N승 M패) 시스템을 통해 공부 자극과 동기부여를 극대화하는 모바일 웹/앱 서비스입니다.

---

## 🌟 핵심 기능 구현 현황

### 1. [가장 중요] 친구 실시간 스카 위치 & 우리 학교 학생 확인
- **친구 위치 실시간 지도/리스트**:
  - 내 친구가 지금 '어느 스터디카페'에 있는지 대화형 지도(Leaflet 기반)와 카드 리스트로 한눈에 파악.
  - 지도 핀 및 카드에 "내 친구 N명 열공 중" 배지와 실시간 프로필 사진 스택 노출.
- **교내 학생(한국고등학교) 현황**:
  - 각 스터디카페 지점별로 우리 학교 학생 중 누가 이용 중인지 확인 가능.
  - "학생 명단 보기"를 통해 학년/반, 공부 상태, 오늘 순공 시간 확인 및 즉시 대결 신청 가능.
- **실시간 상태 공유**:
  - `공부 중 🔥` (초록 불 + 집중 펄스 효과)
  - `휴식 중 ☕` (주황 불)
  - `퇴실 / 미입실 💤` (회색 불)

### 2. 순수 공부 시간(열공 타이머) 측정
- **스카 도착 후 원터치 체크인(입실) & 타이머 작동**:
  - 스터디카페 입실 처리 후 '공부 시작' 버튼으로 초 단위 순수 공부 시간(순공) 측정.
  - 일시정지 및 휴식 전환 모드 제공으로 거짓 공부 시간 방지.
  - 일일 목표 달성률(%) 및 진행률 그래프 실시간 표시.
  - 타이머 작동 시 진행 중인 1:1 대결 상대와의 순공 격차도 실시간으로 함께 갱신.

### 3. 친구 간 1:1 공시 대결 & 누적 상대전적 시스템 (핵심)
- **1:1 대결 신청**:
  - 같은 스카에 있거나 친구 목록에 있는 학생에게 오늘 하루 '순공 시간 대결' 신청.
- **상대전적 자동 노출 & 영구 보존**:
  - 대결 신청 모달 및 대결 진행 창에서 **`상대전적: N승 M패 (승률 XX%)`** 가 굵직하게 자동 노출되어 승부욕 자극!
  - 대결 종료 후 승/패 결과가 프로필과 두 사용자 간의 누적 대결 기록에 영구 보존 (`head_to_head` 테이블).
- **실시간 대결 현황판**:
  - 내 순공 시간 vs 상대방 순공 시간 비율 게이지 바.
  - 실시간 리드 상태 안내 (예: "🔥 내가 +20분 앞서는 중!", "⚡ 이서준 학생이 +20분 앞서는 중! 역전해보세요!").
  - "오늘 대결 종료 & 승패 전적 갱신" 버튼을 통해 승패를 정산하고 상대전적 즉시 갱신.

### 4. 스카 랭킹 시스템
- **지점별 / 학교 전체 순위**:
  - 내가 입실한 스터디카페 내 한국고 학생 랭킹 제공.
  - 학교 전체 학생 랭킹 제공.
- **기간별 필터**:
  - 오늘 하루 순공 랭킹 및 이번 주 누적 순공 랭킹.
  - 🥇 1위(금메달), 🥈 2위(은메달), 🥉 3위(동메달) 배지 제공.

## 🚀 빠른 시작 가이드 (실행 방법)

### 1. 자동 실행
- `run.bat` 파일을 더블 클릭하여 실행합니다.

또는 터미널에서 다음 명령어를 실행합니다:
```bash
python -X utf8 main.py
```

### 2. 브라우저 접속
- 주소: [http://localhost:8000](http://localhost:8000)
- 모바일 화면 비율(Mobile Shell Layout)로 디자인되어 스마트폰이나 PC 브라우저 모두에서 최적의 UI로 동작합니다.

## 💡 다자간 시뮬레이션 (계정 전환 기능)

화면 우측 상단의 **[계정 드롭다운]** 을 통해 여러 학생 계정으로 손쉽게 전환할 수 있습니다:
1. **김민준(나)**: 현재 2학년 3반, 작심 스카에서 이서준과 대결 중 (이전 전적: 3승 2패)
2. **이서준**: 민준의 라이벌이자 절친, 같은 작심 스카에서 열공 중
3. **박도현**: 초심 스카에서 휴식 중 (이전 전적: 1승 1패)
4. **최수아**: 시작 스카에서 공부 중 (이전 전적: 2승 4패)
5. **정채원**: 1학년 후배 학생
6. **강지훈**: 현재 미입실/외출 상태

> **테스트 팁**:
> '김민준'으로 순공 타이머를 켜두거나 대결 결과를 정산해보고, 상단에서 '이서준'으로 전환하여 양측의 상대전적이 `4승 2패` 등으로 실시간 영구 반영되는 과정을 바로 확인하실 수 있습니다.

## 🛠️ 기술 스택 및 아키텍처

- **Backend**: Python 3.12, FastAPI, SQLite3 (영구 데이터베이스 및 트랜잭션 관리), Uvicorn
- **Frontend**: HTML5, Tailwind CSS (반응형 모바일 퍼스트), Leaflet.js (스터디카페 위치 인터랙티브 지도), Vanilla JavaScript SPA
- **Database Schema**:
  - `users`: 학생 프로필, 학교/학년, 소속 스카, 실시간 상태, 누적 순공 시간
  - `study_cafes`: 스카 지점명, 도로명 주소, 위도/경도, 좌석 정보, 시설 안내
  - `friendships`: 친구 관계 매핑
  - `head_to_head`: 사용자 간 역대 1:1 상대전적 (승/패/무승부 영구 누적)
  - `battles`: 일일 대결 세션, 실시간 측정 시간, 최종 승자
  - `study_logs`: 순공 시간 히스토리 로그
